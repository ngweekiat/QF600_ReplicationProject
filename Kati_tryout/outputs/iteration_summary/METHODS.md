All comparisons use the existing 72 test return months, January 2020--December 2025. Kati OOS labels overlap this test history; no separate unseen confirmation is claimed. Annual expanding coefficient refits and monthly portfolio updates are preserved. P(better) is the fraction of 10,000 paired circular-block bootstrap samples (six-month blocks, seed 20261102) with a positive net-Sharpe difference, with half weight to numerical ties. It is not a frequentist p-value or a Bayesian probability of future outperformance. Net Sharpe uses gross-return volatility, following the paper convention. Acceptance is P(better) >= 80% against the last accepted version, not against Market. Identical strategies are not accepted as an improvement. Iteration 1 is retained as an existing design, without a statistical claim. Drawdown is descriptive and adds no rejection gate. Decisions use already inspected test outcomes; subsequent reported performance on those same months is selected-sample evidence, not independent validation. The experiment log retains rejected trials. Nested hyperparameter searches and earlier research choices are not fully corrected by these ten comparisons. Cumulative returns add monthly net excess returns, matching the paper replication code (cumsum(r-tc)). Additive drawdown is the cumulative sum minus its running maximum including initial zero; multiply by 100 for percentage points. Relative performance is the cumulative difference against Market. Additive drawdown is a reporting extension of the paper chart convention, not a verified drawdown definition in the paper or a total-wealth loss. TE 1% is an ex-ante pretest calibration target, not a hard realised cap. Base markets, stock screens, selected 50, dates, costs and risk equations are retained except for each explicitly tested override. Exit 120 changes buffering within the same US large-cap candidate population and may change the stock count; costs x2 are applied both when fitting and when trading. The original wider covariance cache may supply extra buffered stocks, only after equality checks against common base covariance entries. No 250-stock breadth experiment is part of this ten-step sequence.
