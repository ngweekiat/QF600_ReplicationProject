# Deviations from the paper and the R reference

Every place this replication differs from Jensen, Kelly, Malamud & Pedersen (2026) or from the
authors' R code (`reference/jkmp_r/`) is listed here. Add a row whenever code or config departs
from either, in the same change. This file feeds the report's methodology section.

Columns: **Paper / R** is what the authors do; **Ours** is what we do; **Why** is the reason;
**Where** is the config key or module.

## 2. Where we follow the R code over the paper's text

| # | Topic | Paper says | R code does (we copy) | Where in R |
| --- | --- | --- | --- | --- |
| R1 | Random-feature scale | Weights ~ N(0, η²I), η ∈ {e⁻³, e⁻²} | `g` ∈ {e⁻³, e⁻²} is the **variance** | `rff` in `0 - Return prediction functions.R` |
| R2 | Portfolio-ML lag weights | Eq. 24: multiply by (I − m) | Normalise by the inverse of the truncated sum (`solve(const)`) | `pfml_input_fun` |
| R3 | Covariance units | — | Daily factor covariance × 21 → **monthly** Σ (comment says "annualize") | `3 - Estimate Covariance Matrix.R` |
| R4 | Realised utility / net Sharpe | Eq. 11 uses net-return variance | Uses **gross**-return variance | `pf_summary` in `6 - Base analysis.R` |
| R5 | Static-ML\* variance add-on | v ∈ {1, 2, 3} | Σ + g·diag(Σ), g ∈ {0, 1, 2} (v = 1 + g) | `sigma_gam_adj` |
| R6 | Static-ML\* cost scaling | Divide Λ by φ | Multiply Λ by k = 1/φ | `static_implement` |
| R7 | First month's starting weights | — | Start from value weights, not zero | `initial_weights_new(w_type = "vw")` |
| R8 | Feature ranks | Map the cross-sectional rank into [0, 1] | `ecdf(x)(x)` (ties take the max rank), then raw values exactly 0 are set to rank 0; missing → 0.5 | `1 - Prepare Data.R`, feature standardization |
| R10 | Trading speed m (Lemma 1) | Exact fixed point | 10 fixed-point iterations from the G = 11ᵀ closed form; not fully converged (Lemma 1 residual ~1e-4; on the real 82-stock, \$10B problem m is within 9e-4 of the converged value). We keep 10 (`investor.m_iterations`) and compute the start value in the algebraically identical, cancellation-free form 2(σ̂ + √(σ̂² − 4I))⁻¹ | `m_func` |
| R11 | Table 2 statistics | Eq. 11 uses net-return variance | Vol, SR_net and Utility all use the variance of **gross** returns | `pf_summary` in `6 - Base analysis.R` (same as R4) |
| R12 | Portfolio-ML signals | Signals s_t = RF(char) scaled by 1/σ (Eq. 37), weighted lags | Unbalanced panel (`balanced = F`): at each lag month the features of the **current** universe stocks are demeaned, a constant added, every column scaled to unit sum of squares, then rows × 1/vol with vol = √diag Σ of *that* month (missing → the month's median); RFF are raw cos/sin (no p^{-1/2}, which the column scaling would undo); 12 signal months (lb = 11) plus one more for Ω_{t−1}; ΔΩ = Ω_t − diag(g_t)Ω_{t−1} | `pfml_input_fun` |
| R13 | Portfolio-ML ridge | Eq. 36 penalises the signal coefficients | `solve(denom + l*diag(p+1))`: the **constant** is penalised too; Σ̄ and r̄ are *means* over months (not sums); realised utility r̃ᵀβ − ½βᵀΣ̃β, cumulative mean from the first hp year, best (g, p, λ) across all g at each December | `pfml_search_coef`, `pfml_hp_reals_fun`, `pfml_implement` |
| R9 | History requirement | Signals for the current and past 11 months | Row 12 back (lb_hor + 1) must be exactly 12 months earlier, checked *after* the screens — 13 consecutive screened months | `1 - Prepare Data.R`, valid lookback screen |
